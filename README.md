# DETAILPRO — сайт детейлинг-студии

Одностраничный сайт студии: услуги и цены, работы, преимущества, этапы, отзывы, вопросы, форма записи и контакты.

Онлайн-версия: https://vmmcode.github.io/detailpro/

## Как посмотреть локально

Распакуйте архив и дважды нажмите на `index.html`: сайт откроется в браузере, интернет не нужен. Подробная инструкция с мобильной версией — в файле [КАК-ОТКРЫТЬ.txt](КАК-ОТКРЫТЬ.txt).

## Что внутри

```
index.html              вся страница: тексты, цены, контакты, данные для поисковиков
КАК-ОТКРЫТЬ.txt         короткая инструкция, как посмотреть сайт
assets/
  css/tokens.css        цвета, шрифты, размеры, отступы, скорость анимаций — все настройки внешнего вида
  css/base.css          базовые стили страницы: шрифты, скроллбар, выделение текста, фокус
  css/components.css    общие элементы: кнопки, стрелки, чипы, карточки, заголовки
  css/<секция>.css      стили отдельных блоков: header, hero, services, gallery, booking, footer и т. д.
  js/config.js          настройки: режим отправки формы, анимация фар в первом экране
  js/<модуль>.js        поведение: меню, слайдеры, лайтбокс, вопросы, форма, анимации
  js/vendor/            библиотека nice-select2 для списка услуг в форме (MIT)
  img/                  фотографии
  img/hero-sequence/    80 кадров анимации «включение фар» в первом экране
  fonts/                шрифт Onest
  icons/                иконка сайта и иконка для iPhone
```

Сайт сделан на чистых HTML, CSS и JavaScript, без фреймворков и сборки. Все пути относительные: сайт работает и в корне домена, и в подпапке.

## Где что менять

Файлы открываются в любом текстовом редакторе, удобнее всего в бесплатном VS Code. Нужное место проще всего найти поиском (Ctrl+F) по фразе с сайта.

### Тексты

Все тексты лежат в `index.html`. Каждый блок начинается с комментария-заголовка, по нему удобно искать:

| Комментарий в коде | Блок на сайте |
|---|---|
| `<!-- шапка -->`, `<!-- мобильное меню -->` | логотип, меню, телефон, кнопка записи |
| `<!-- hero -->` | первый экран: подзаголовок и кнопка |
| `<!-- вступление -->` | «О студии» |
| `<!-- услуги и цены -->` | прайс из 6 услуг |
| `<!-- галерея -->` | работы и слайдер «до/после» |
| `<!-- преимущества -->` | цифры и карточки «Почему мы» |
| `<!-- этапы -->` | «Как мы работаем» |
| `<!-- отзывы -->` | отзывы клиентов |
| `<!-- faq -->` | частые вопросы |
| `<!-- запись -->` | форма записи |
| `<!-- контакты -->` | карта, адрес, телефон, режим работы, мессенджеры |
| `<!-- футер -->` | нижняя часть страницы |

Сочетание `&nbsp;` в тексте — неразрывный пробел: он не даёт предлогу или знаку ₽ оторваться от слова при переносе строки. При правке сохраняйте его.

Вопросы и ответы FAQ продублированы в начале файла, в блоке `"FAQPage"`: это нужно поисковикам. Если меняете ответ на странице, поправьте его и там.

### Цены

Ищите `от&nbsp;4&nbsp;500&nbsp;₽` и т. п. в блоке «услуги и цены». Три цены повторяются в первом ответе FAQ и в блоке `"FAQPage"` в начале файла.

### Контакты

Телефон встречается в нескольких местах: шапка, мобильное меню, контакты, футер, сообщение об ошибке формы и блок `"AutoRepair"` в начале файла. Меняйте и видимый текст, и ссылку `tel:+74950000000`. Адрес, e-mail, режим работы и координаты для поисковиков тоже лежат в блоке `"AutoRepair"`.

Адрес сайта указан в тегах `canonical`, `og:url`, `og:image` и в блоке `"AutoRepair"`: сейчас там `https://vmmcode.github.io/detailpro/`. При переезде на домен студии замените его в этих четырёх местах. Адрес картинки-превью должен оставаться полным, с `https://`, иначе мессенджеры её не покажут.

### Цвета и шрифты

Всё в `assets/css/tokens.css`. В начале файла — базовая палитра (`--graphite-900`, `--silver-300` …), ниже — «смысловые» цвета: `--color-bg` — фон, `--color-text` — текст, `--color-accent` — серебряный акцент. Значения, поменянные здесь, применятся по всему сайту.

Размеры заголовков — переменные `--fs-h2`, `--fs-h3` и т. д., скорость анимаций — `--dur-…`. Шрифты подключены в `assets/css/base.css`, файлы лежат в `assets/fonts/`.

## Как подключить форму

Форма собирает имя, телефон, марку авто, услугу, комментарий, согласие, UTM-метки из адреса страницы (`utm_source` и др.) и адрес страницы (`page_url`). Скрытое поле-ловушка отсеивает спам-ботов: если оно заполнено, форма показывает «успех», но ничего не отправляет.

Форма есть в секции «Запись» и во всплывающем окне, которое открывают все кнопки «Записаться». Окно — копия формы из секции, её создаёт скрипт при загрузке страницы. Поэтому поля и тексты меняются только в секции `<!-- запись -->`, окно подхватит их само.

Сейчас форма работает в демо-режиме: показывает «Заявка отправлена», но никуда её не отправляет. Режим меняется в `assets/js/config.js`:

```js
window.DETAILPRO.FORM_CONFIG = {
  mode: 'demo',     // 'demo' | 'fetch' | 'native'
  endpoint: '',     // адрес обработчика для режима 'fetch'
  timeout: 10000,   // через сколько мс считать отправку неудачной
};
```

- `demo` — имитация отправки, ничего никуда не уходит.
- `fetch` — заявка отправляется POST-запросом на адрес из `endpoint`, страница не перезагружается.
- `native` — форма уходит средствами браузера на адрес из атрибута `action` у формы, как обычная HTML-форма. Так же она отправляется, если в браузере выключен JavaScript.

### Вебхук (Make, Zapier, n8n, Albato, свой сервер)

```js
mode: 'fetch',
endpoint: 'https://hook.example.com/abc123',
```

Форма отправит поля как `multipart/form-data`. Ответ с кодом 200–299 считается успехом. Любой другой ответ или таймаут — ошибка: посетитель увидит сообщение с телефоном, введённые данные останутся в полях.

### WordPress

- Свой обработчик: создайте PHP-обработчик (через `admin-post.php` или REST-маршрут), впишите его адрес в `endpoint`, режим — `fetch`.
- Contact Form 7: создайте форму с полями тех же имён (`name`, `phone`, `car`, `service`, `comment`, `consent`) и отправляйте на её REST-адрес `/wp-json/contact-form-7/v1/contact-forms/<ID>/feedback` (режим `fetch`). Свежие версии CF7 требуют своих служебных скрытых полей (например, `_wpcf7_unit_tag`), их нужно добавить в форму. Проще вариант со своим обработчиком.

### PHP-скрипт

Положите на хостинг, например, `send.php`, который принимает `$_POST` и отправляет письмо. В `index.html` у формы укажите `action="send.php"`, в `config.js` — `mode: 'native'`.

### Битрикс24, amoCRM, Telegram

Только через серверную прослойку: PHP-скрипт или вебхук-сервис принимает заявку и сам вызывает API CRM или бота. Адрес прослойки указывается в `endpoint`.

**Важно: токены CRM, ключи API и токены Telegram-ботов никогда не вписывайте в файлы сайта.** Всё, что лежит в `index.html` и `assets/`, может прочитать любой посетитель. Токены хранятся только на сервере.

### События для аналитики

После успешной проверки полей форма отправляет событие `detailpro:submit`, после успешной отправки — `detailpro:success`. Пример цели для Яндекс Метрики:

```html
<script>
  document.addEventListener('detailpro:success', function () {
    ym(XXXXXXXX, 'reachGoal', 'booking');
  });
</script>
```

## Как опубликовать

### GitHub Pages

Сайт уже лежит в репозитории `VMMcode/detailpro`. В настройках репозитория: Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`. Через минуту-две сайт откроется по адресу https://vmmcode.github.io/detailpro/. Пустой файл `.nojekyll` в корне нужен, чтобы GitHub отдавал файлы как есть.

### Любой статический хостинг

Подойдёт обычный хостинг (Timeweb, Beget, REG.RU и т. п.), Netlify или Vercel. Загрузите содержимое папки целиком, чтобы `index.html` лежал в корне сайта (`public_html` или `www`). После переезда на свой домен замените адрес сайта в мета-тегах — см. «Контакты» выше.
